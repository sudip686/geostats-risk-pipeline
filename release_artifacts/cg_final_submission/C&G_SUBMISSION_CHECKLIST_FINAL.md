# Computers & Geosciences Final Submission Checklist

Guide used: https://www.sciencedirect.com/journal/computers-and-geosciences/publish/guide-for-authors

## 1. Essential Files (Must Upload)
- [ ] `01_Title_Page.docx`
- [ ] `02_Highlights.docx` (3-5 bullets, each <=85 characters)
- [ ] `04_Manuscript.docx` (double spacing + line numbers)
- [ ] `05_Declaration_of_Interest.docx`
- [ ] `Cover_Letter.docx`
- [ ] `Tables_with_Captions.docx`
- [ ] `Figures_with_Captions.docx`
- [ ] `Figure_1.tif` to `Figure_12.tif`

## 2. Optional / Conditional Files
- [ ] `03_Graphical_Abstract.tif` (if graphical abstract requested)
- [ ] `Submission_Checklist.pdf`

## 3. Supplementary Package
- [ ] `Supplementary_Code_S1.zip`
- [ ] `Supplementary_Data_S1.zip`
- [ ] `Supplementary_Data_S2.zip`
- [ ] `Supplementary_Table_S3.csv` to `Supplementary_Table_S13.csv`
- [ ] `Supplementary_Table_S6_DII_summary.csv`
- [ ] `Supplementary_Table_S7_AIR_headline.csv`
- [ ] `Supplementary_Table_S10_rank_stability_summary.csv`
- [ ] `Supplementary_Visualization_S3_3D_Drillholes.html` (if portal allows)

## 4. Files NOT to Submit
- [ ] Any backup/temp file (`*.backup*`, `*.pre_*`, `*.tmp*`)
- [ ] Internal audit logs or revision notes
- [ ] Unused figure variants (`Figure_13+`, `Figure_5A/5B/5C`)

## 5. Strict Content Cross-Check
- [ ] Every cited figure in manuscript exists (`Figure_1`-`Figure_12`)
- [ ] Every cited supplementary table exists (`S3`-`S13`)
- [ ] Highlights comply with length/count
- [ ] Keywords count <=6
- [ ] Data/code availability statements aligned with proprietary-data policy

## 6. Step-by-Step Submission Flow (Editorial Manager)
1. Start new submission and confirm article type.
2. Enter manuscript metadata (title, authors, affiliations, abstract, keywords).
3. Upload main manuscript: `04_Manuscript.docx`.
4. Upload title page and highlights.
5. Upload figures and `Figures_with_Captions.docx`.
6. Upload `Tables_with_Captions.docx`.
7. Upload declarations/conflict documents.
8. Upload supplementary package (code/data/tables).
9. Run PDF proof check for equations, figure labels, and table alignment.
10. Final pre-submit check against this checklist and `SUBMISSION_FILE_MANIFEST.txt`.

## 7. GitHub Release Artifact Check
- [ ] Final package mirrored to `repo/release_artifacts/cg_final_submission/`
- [ ] `SUBMISSION_FILE_MANIFEST.txt` present
- [ ] `C&G_SUBMISSION_CHECKLIST_FINAL.md` present
